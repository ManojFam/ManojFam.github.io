Attendance Management System

PythonDjangoSQLiteUsed at work

Our English courses tracked attendance in Excel. Every month meant another file, and nobody could quickly see a student's overall attendance. I built a web app to replace it.

  • Trainers mark Present, Absent or Leave in the browser, with a "set everyone Present" shortcut
  • Class sessions are created automatically from each group's teaching days
  • Admin staff get reports, flags for students under 80%, and CSV export
  • Changing a class schedule never deletes attendance already entered
View on GitHub → 
# the one formula every report uses
Attendance % = Present
             / (Sessions to date
                − Holiday − Cancelled)
             × 100

# Absent and Leave stay in the count.
# Future sessions are never counted.

One formula in one place, so the trainer page, the admin and the reports always agree. Read the story.

Network Health Checker

PythonCLINetworking

Most network tickets start with the same question: what is up, what is down, and what is half-working? netcheck answers it.

  • Pings each device and checks the ports it should have open
  • Sweeps a subnet to find live hosts
  • Saves CSV and HTML reports you can attach to a ticket
  • Uses Nagios-style exit codes, so it can raise alerts from Task Scheduler or monitoring tools
